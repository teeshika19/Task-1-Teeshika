# Basic Encryption and Decryption

## Project Description

This is a Python-based Encryption and Decryption program that uses the Caesar Cipher technique to encode and decode messages.

The program allows users to enter a message and a numerical shift key. It uses the shift key to replace each letter with another letter a certain number of positions away in the alphabet.

The program includes two main functions:

- Encryption: Converts the original message into an encrypted message by shifting each letter forward in the alphabet.
- Decryption: Converts the encrypted message back into its original form by shifting each letter backwards using the same shift key.

The program supports both uppercase and lowercase letters while keeping spaces, numbers, and punctuation unchanged. It also checks that the shift key entered by the user is a valid number.

## How to Run

Requirements:
- Python 3 installed.

Steps:
1. Open the project folder.
2. Open the Python file using Python IDLE or another Python editor.
3. Run the program.
4. Enter the message you want to encrypt.
5. Enter a numerical shift key.
6. View the original, encrypted, and decrypted messages.

No additional libraries need to be installed.
