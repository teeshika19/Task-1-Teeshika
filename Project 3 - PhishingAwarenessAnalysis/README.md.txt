# Phishing Awareness Analysis

## Description
This project focuses on analysing phishing emails and messages to identify suspicious links, misleading information and common warning signs. It also includes email header and URL inspection, phishing scenarios, a triage checklist and a decision tree to help classify potential threats as safe, suspicious or malicious.

## How to Run
This project is a documentation and analysis-based cybersecurity project. It does not require any commands or software to run.

To view the project, open the project report (PDF) and review the phishing scenarios, checklist and decision tree.
